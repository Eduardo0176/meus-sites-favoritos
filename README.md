# Meus sites favoritos

Página web desenvolvida em HTML como atividade prática da unidade sobre a Sociedade da Informação e da Comunicação. A página reúne cinco sites favoritos, cada um com o nome, uma imagem e o link de acesso.

**Autor:** Seu Nome

## Sites da página

| Site | Link |
|---|---|
| YouTube | https://www.youtube.com |
| Instagram | https://www.instagram.com |
| GitHub | https://github.com |
| Spotify | https://www.spotify.com |
| Google | https://www.google.com |

## Requisitos da atividade atendidos

- Título da aba do navegador: **Meus sites favoritos**
- Título do corpo da página: **Meus sites favoritos: Seu Nome**
- 5 imagens de sites favoritos
- Nome de cada site acima da imagem (tag `<h1>`)
- Link de cada site abaixo da imagem (tag `<a>`)
- Opcional: as imagens também funcionam como links

## Estrutura do projeto

└── README.md

## Como executar

1. Baixe ou clone este repositório
2. Mantenha o `index.html` e as imagens na mesma pasta
3. Dê dois cliques no `index.html` para abrir no navegador

Ou acesse a página online (GitHub Pages):
https://seu-usuario.github.io/meus-sites-favoritos
